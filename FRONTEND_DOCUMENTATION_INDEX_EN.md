## 🎯 How-To Guides

### Learning to Create a Component

```
1. Read [Components Guide](FRONTEND_COMPONENTS_EN.md)
2. Analyze existing components
3. Create new component
4. Follow [Best Practices](FRONTEND_BEST_PRACTICES_EN.md)
5. Test thoroughly
```

### Adding a New Page

```
1. Study [Pages Guide](FRONTEND_PAGES_EN.md)
2. Define route in App.jsx
3. Create new page
4. Use [Context and Hooks](FRONTEND_CONTEXT_HOOKS_EN.md)
5. Add router logic
```

### Fixing a Bug

```
1. Understand error message
2. Read related documentation
3. Search for similar code
4. Apply fix
5. Test
```
